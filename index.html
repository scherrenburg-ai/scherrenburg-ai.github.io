Gmail Triage App

A personal tool that helps one person keep his own Gmail inbox under control.

Not a public service. This app is used by exactly one person: the owner of the Google account it connects to. There are no sign-ups, no other users and no server run by this app.

What it does

  • Reads the metadata of recent messages in the owner's inbox with read-only Gmail access: sender, recipients, subject, date, labels, read/unread status, unsubscribe headers and the short preview text that Gmail provides. It does not download full message bodies or attachments.
  • Classifies each message (for example: newsletter, service, club; needs action; security-related; how urgent) with an AI classification model.
  • Writes a daily summary for the owner and proposes which messages need attention, and gives advice on which newsletters to unsubscribe from or filter.

What it does not do

  • It cannot send, delete, archive or change email: it only has read-only access.
  • It does not sell, share for advertising, or publish any email data.

How Google user data is handled is described in the privacy policy.
