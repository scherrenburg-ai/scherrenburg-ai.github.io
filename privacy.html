Privacy policy

Gmail Triage App · last updated 29 September 2026

Gmail Triage App is a personal tool. The only Google account it accesses is the account of its owner, who is also its only user. This policy describes exactly what the app does with that Google user data.

Data the app accesses

With the read-only Gmail scope (gmail.readonly) the app reads, for recent messages in the inbox: sender, recipients, subject, date, labels, read/unread status, unsubscribe headers and the short preview text (snippet) that Gmail provides. It does not download full message bodies or attachments, and it does not access contacts, calendar or any other Google service.

How the data is used

Only to help the owner sort his own inbox: classifying messages, flagging the ones that need attention, writing a daily summary and advising which newsletters to unsubscribe from or filter. The app does not use the data for advertising, does not sell it and does not build profiles with it.

Where the data is stored

On the owner's own computer, in local files. The OAuth token is also stored there. The app has no server and no database of its own. The owner can delete these files at any time.

Services that process the data

  • TypeSafe (typesafe.ai): sender, recipients, subject, date and preview text (including short previews of earlier messages in the same thread) are sent to TypeSafe's API, whose model classifies the messages. According to TypeSafe, requests and responses are not used to train its models.
  • Anthropic (Claude): the owner's AI assistant reads the results, including sender and subject, to review unclear cases and to write the daily summary.

Data is not shared with anyone else.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
