# scherrenburg-ai.github.io

Homepage, privacy policy and terms of use for **Gmail Triage App**, a personal single-user Google OAuth app.

Google requires these public pages, on a domain verified in Search Console, before an external OAuth app can
move from *Testing* to *In production*. That is the only purpose of this repository.

- https://scherrenburg-ai.github.io/
- https://scherrenburg-ai.github.io/privacy.html
- https://scherrenburg-ai.github.io/terms.html
